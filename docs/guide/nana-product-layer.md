# NanaBobo 业务边界

## 当前纵切

首页工作流按“登录 → 连接直播间 → 查看当前直播间”组织，并连接以下真实能力：

1. B站二维码登录、账号状态和退出登录。
2. 按直播间号查询公开房间信息。
3. 每 60 秒记录当前房间的脱敏在线人数、关注数和直播状态快照。
4. 通过公共直播间长连接接收弹幕；主播助手只显示消息，不发送弹幕。
5. 在数据统计页查看快照趋势，在历史记录页按房间清理快照。

Rust 侧持有 B站请求和登录 Cookie，Vue 侧只消费 `src/contracts/bilibili.ts` 中的脱敏契约。普通设置经宿主 storage host API 保存（localStorage 写穿到宿主文件），但登录态只能进入 Windows OS Keyring。

当前只维护一个直播间连接。房间号与脱敏快照使用命名空间化本地存储；弹幕原文只存在于当前页面内存，不写入持久化存储。
