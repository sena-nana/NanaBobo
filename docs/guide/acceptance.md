# 验收矩阵

| 场景 | 预期行为 |
| --- | --- |
| 启动桌面应用 | 侧栏为首页 / 主播助手 / 数据 / 设置，不出现未接通功能 |
| 未登录 | 侧栏底部显示登录入口；不显示房间输入或伪造账号 |
| 二维码过期 | 明确显示过期状态，可重新生成二维码 |
| 扫码成功 | 显示脱敏账号信息，登录态写入 OS Keyring |
| 重启应用 | 通过真实账号状态接口恢复登录状态 |
| 退出登录 | 清除 Keyring 凭据并回到未登录状态 |
| 恢复房间 | 登录成功后恢复上次房间号并自动查询，失败时保留可编辑输入 |
| 统计快照 | 当前房间每 60 秒记录脱敏快照；每个房间最多保留 2,000 条 |
| 数据 | 同一页用趋势 / 历史查看快照，并按房间清理本地脱敏快照 |
| 弹幕助手 | 只接收当前房间弹幕，显示连接/重连/停止状态，不提供发送入口 |
| 房间号为空或非法 | 阻止请求并显示输入错误 |
| B站接口限流或不可用 | 显示可恢复错误，不泄露上游响应 |
| 弹幕连接失败或中断 | 使用结构化可恢复错误并支持重连，不泄露 Cookie、Token、上游原始响应，弹幕原文不写入持久化存储 |

## 检查命令

`cargo test`

`cargo build -p nanabobo-app` 后手动冒烟 `target/debug/nanabobo.exe`
